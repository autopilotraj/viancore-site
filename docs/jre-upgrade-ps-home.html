Upgrading the JRE Under PS_HOME

A short, mechanical process on PeopleTools 8.59 and newer — but easy to get wrong if you don't know that the "jre" directory hasn't actually held a JRE since JDK 11.

Overview

PeopleTools 8.59 and later expect a Java runtime under $PS_HOME, referenced by convention as the jre directory. Keeping this current matters for security patching, and Oracle ships updates for it regularly through My Oracle Support. The process itself is a handful of steps; the only real risk is skipping the backup or forgetting which processes need to be stopped first.

Upgrading on Linux
  • Download the target JDK build for Linux x86-64 from My Oracle Support (search Doc ID 1439822.1, "Supported Java SE Downloads on MOS," for the currently supported version for your PeopleTools release).
  • Unpack the tarball to a temporary location: tar zxvf jdk-<version>_linux-x64_bin.tar.gz
  • Shut down any application servers or process schedulers running under the $PS_HOME you're updating.
  • Back up the existing jre directory under $PS_HOME before touching it.
  • Remove the contents of the jre directory.
  • Copy the contents of the extracted JDK directory into the now-empty jre directory under $PS_HOME.
  • Start the application servers and process schedulers back up and confirm the environment comes up clean.
Upgrading on Windows

The Windows installation steps follow Oracle's own JDK installer flow rather than a manual copy — see Oracle's JDK installation guide for Microsoft Windows platforms for the current, version-specific steps.

A naming quirk worth knowing

There is no JRE starting with JDK 11 — Oracle merged the JRE into the JDK distribution. PeopleTools still calls the directory jre under $PS_HOME for backward compatibility, but what you're actually installing there from JDK 11 onward is a full JDK.

Summary

Stop the domains, back up the existing directory, swap in the new JDK build, and bring the domains back up — that's the entire upgrade. The only step people skip is the backup, and it's the one you'll want the one time the upgrade doesn't go cleanly.
